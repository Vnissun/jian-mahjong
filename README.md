# 集安麻将--吉林通化集安麻将玩法，撅夹钓

本仓库根目录即原工程，使用 **Cocos Creator 3.8.8**。外层 `assets` 是历史代码，`_disabled` 中的测试和联机模块不参与游戏构建；请修改本目录 `assets/scripts`。

## 好友线上对战

执行 `npm run build:server`、`npm start`，打开 `http://127.0.0.1:7458`。大厅可好友开房、复制邀请链接或输入六位房间号加入。房主在开局前可增删机器人；真人全部准备后房主开局，空位自动补齐机器人。每位玩家仅能看到自己的暗手，支持刷新及断线重连。详见 [BOTS-UPDATE.md](BOTS-UPDATE.md)；公网部署见 [DEPLOY.md](DEPLOY.md)。

## 运行

1. 在 Cocos Dashboard 中添加本目录，使用 Creator 3.8.8 打开，等待资源导入完成。
2. 打开 `assets/game.scene`，点击编辑器预览。
3. 大厅选择底分、满贯、封圈、七小对和吃牌，点击“开始游戏”。默认底分 1、满贯 32、封圈 3、七小对和吃牌开启。当前为一人对三名 AI。

本次已生成 `build/web-repaired`。在本目录执行 `npm run preview` 或 `node tools/serve.cjs`，打开 <http://127.0.0.1:7457>。服务仅监听本机。停止服务按 Ctrl+C。

重新构建可在编辑器选择 Web Desktop，或执行 PowerShell：

```powershell
& 'C:\ProgramData\cocos\editors\Creator\3.8.8\CocosCreator.exe' --project $PWD.Path --build 'configPath=buildConfig.web.json'
```

编辑器安装位置不同时调整命令。构建配置指定游戏场景、横向网页模板和输出目录。Cocos 的命令行构建成功退出码为 36。

## 操作

- 点手牌一次选中，第二次点击同一张或点击“出牌”确认。
- 报听：仅单吊、夹、撅、对倒可报；普通两面听不可报听，可继续换牌。点击“报听”，仅亮起合法弃牌，点选后再次点击确认。若有多个听口，再选择声明方案；如 1234 单吊 1 或 4，必须选一个，另一个不能胡。声明时锁定听口及手牌，以后只能打出新摸到的牌，不可换听，仍可胡牌；允许不影响原听口的暗杠、已开门点杠、加杠及已有字杠补毛。
- 杠：点“杠”，从组合菜单选择普通暗杠、特殊杠、加杠或补毛。“过”可取消。
- 他家出牌时，先处理胡牌机会，再处理碰杠。选择“过”放弃本次机会。
- 吃牌只吃上家的数牌；胡、碰、杠机会全部处理后，点击“吃”选择三张顺子的组合，吃后出一张牌。
- 报听者旁边向所有人显示单吊、对倒、夹胡或撅等具体听法。
- 点击任意自己的手牌可查看余量；报听后持续显示听牌余量。估计为 4－公开已见－自己持有，包含他家暗手及牌墙，不透露暗牌。
- 流局或胡牌后查看结算，手动进入下一局；大厅按钮可重新开桌。

## 规则及计分

以用户确认后的规则和 `assets/scripts/config` 为依据：

- 136 张牌，庄家 14 张，闲家 13 张，尾部保留 14 张补牌区。
- 固定允许吃上家数牌，允许碰、明杠、暗杠和加杠；仅加杠可被抢胡。
- 普通胡必须有幺九、刻子（中发白对豁免刻子）、不缺门；纯清/混清豁免缺门。七小对豁免刻子，但仍必须有幺九、不缺门（允许清一色），且胡前必须报听单吊。
- 自摸、点炮、抢杠使用同一套手牌及副露校验；抢杠时真人可以选择胡或过。
- 每次胡牌由另外三家分别付款，分别计算倍数；有限满贯逐家封顶，新增无限选项（cap=0），不截分。底分最后乘入。
- 胡家与每一付款方中，只要一方为庄家，该笔 ×2，只计算一次。
- 报听对踢默认关闭：双方报听取高；开启则双方相乘。普通 ×2、报撅 ×4，每笔不受第三人影响。对倒、单吊、夹胡归为普通报听。
- 胡家站立 ×2、付款方站立 ×2；双方均站立合计 ×4。
- 自摸每家 ×2。点炮/抢杠的责任方 ×2，其余两家仍按自身规则付款。
- 杠后立即自摸在自摸基础上再 ×2；杠后立即点炮只对责任方在点炮基础上再 ×2。本局早先有过杠不增加之后普通胡牌的倍数。
- 混清一色 ×2；纯清一色总计 ×4，不再重复乘混清。
- 三家清：胡家已开门、另外三家均未开门，固定基础 ×4。四家清：四家均未开门，固定基础 ×16。两者均已包含站立，不再叠加胡家或付款方站立倍数。不能仅凭全桌有三人站立就认定三家清。
- 飘胡／对对胡：四组刻子或杠加一对将，碰出的牌也算；有顺子或吃牌则不算。仅胡牌积分额外 ×2，参与原满贯封顶，不影响杠分和补毛分；不重复叠加到七小对。
- 七小对固定基础 ×8，站立 ×2、普通单吊报听 ×2，形成基础32；点炮或自摸、庄家、清一色等适用倍数继续叠加，不重复乘四家清。
- 杠分和补毛分局内暂存且不公开分值，胡牌或荒庄时统一入账，独立于胡牌分，不参与满贯。
- 四张相同牌的杠基础分：一条/一筒/中发白 2、二筒/八万 4、其余 1；暗杠 ×2；每笔付款任一方为庄家则 ×2。四风/三元组合基础2，补毛基础1。
- 特殊杠：东南西北各一张，或中发白各一张再加一张中/发/白；可攒齐再杠，基础 2 × 暗杠 2，不开门、不允许抢杠，但四张公开。普通四张相同暗杠对他家隐藏。
- 补毛：已成四风杠只补风，三元杠只补中发白；每张其余三家各付底分 1，任一方庄家该笔 ×2。补后尾部补摸，紧接的自摸或点炮适用杠后加成。
- 庄家胡牌或荒庄连庄，闲家胡牌推进庄位，四个庄位完成一封圈。

好友房使用服务端统一规则和逐玩家可见状态，替代停用目录中的旧 P2P 方案。现有封圈流程使用固定座位轮庄，没有实现历史注释中设想的随机换座。

## 验证

```powershell
npm test
npm run typecheck
```

测试使用 TypeScript 编译器，可执行 `npm install` 安装，也可以使用本机 Creator 3.8.8 自带的编译器；其他位置可设置 `TYPESCRIPT_PATH`。类型检查依赖 Creator 首次打开工程生成的 `temp/declarations`。

243 项测试覆盖规则/计分及流程回归。其中包含 100 局固定种子的完整 AI 对局，逐步断言 136 张物理牌和积分守恒。

`npm run test:browser` 使用 Playwright 和本机 Edge 验证大厅、点击出牌、完整对局、结算及返回大厅，截图保存在 `screenshots`。设置 `PLAYWRIGHT_PATH` 可指定 Playwright 模块目录。此测试需先启动预览服务。

`node tools/rules-browser.cjs` 使用受控测试场景检查真实吃牌选项点击、吃后继续出牌、公开报听标签和 A/B/C/D 的逐家报听结算示例。`screenshots/scoring-example.png` 为构造规则示例，并非随机完整对局截图。

具体修复及验证记录见 `REPAIR_NOTES.md`。

参考：[Cocos 3.8 命令行构建文档](https://docs.cocos.com/creator/3.8/manual/zh/editor/publish/publish-in-command-line.html)。

`node tools/waits-browser.cjs` 验证实际编译后的七小对报听与自摸按钮、全场听型、锁听、余量及特殊杠/补毛；使用受控牌局，截图保存在 `screenshots`。

牌面统一使用传统图形：中文数字万字、圆环筒子、竹节条子和幺鸡、风牌与三元；不附加牌名或阿拉伯数字，白板中央为红色方框。`node tools/tiles-browser.cjs` 验证真实选听按钮及全部 34 种牌面；`screenshots/tile-atlas.png` 为牌面总览。

联机验证：`npm run test:server` 包含 10 组服务端/API 测试，其中有 8 局四人完整对战及 HTTP 飘胡结算一致性验证；`npm run test:online` 使用四个独立浏览器会话，检查邀请、准备、开局、不同座位、刷新重连、结算和下一局。

报听后杠牌：每次操作都检查原声明听型和选定听牌；暗杠不得拆走原顺子或将牌中的牌。站立报听不能点杠，已开门者可以三张杠他家一张。已有风/元特殊杠可补同类新摸毛，杠后尾部补牌、可自摸或打牌点炮。宝塔 Node.js 逐步部署说明见 [BAOTA-NODEJS.md](BAOTA-NODEJS.md)。

运行环境已验证 Node.js 16.20.2。宝塔选择此版本，生产入口为 `server/start-production.cjs`；服务端及健康检查不依赖全局 fetch。

手机显示已改为横屏整页适配，电脑保留原方向。已部署站点可仅更新网页包，步骤见 MOBILE-UPDATE.md；全屏按钮需点击触发，iPhone 受浏览器支持限制。

最新版本支持杠后补摸前报听与服务端访问密码，部署必须使用整站反向代理，详见 ACCESS-UPDATE.md。联机洗牌由加密随机数驱动，不存在听牌偏向摸牌。

音效：34种牌中文报牌、吃碰杠补毛报听胡牌等动作语音；按钮/摸牌/出牌/胜负提示由浏览器音频合成。页面左上角可静音和调节音量，设置保存在本浏览器。手机需先点击页面解锁音频。新增语音源在 web-assets/sounds，构建后执行 node tools/sync-web-audio.cjs 同步资源；打包脚本自动同步。


## 从 GitHub 配置部署

仓库不包含现用密码和服务器私有配置。部署前将 `server/production.example.json` 复制为 `server/production.json`，填写域名并修改 `accessPassword`，或设置 `ACCESS_PASSWORD` 环境变量。文档中的 `CHANGE_ME_ACCESS_PASSWORD` 仅为占位文字，必须替换。后台密码文件由服务器生成，不上传版本库。使用 Node.js 16.20.2 和 Cocos Creator 3.8.8；构建产物需自行生成。
